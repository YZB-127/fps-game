# fps-game

浏览器里跑的 3D 第一人称射击游戏。**一个 HTML 文件 + 一个零依赖的 Node.js 服务器**，双击就能开局，支持同一 WiFi 下双人联机单挑。

## 特性

- **两种模式**：单人模式打机器人 / 双人单挑联机 1v1
- **三把枪**：手枪 P9、冲锋枪 MP5、霰弹枪 M870，各自独立的弹匣、射速、散布、后坐力与换弹时间
- **完整 FPS 手感**：Pointer Lock 鼠标视角、WASD 移动、跳跃、冲刺、爆头 ×1.5 判定
- **子弹会被墙和箱子挡住**，不能穿墙打人
- **公平出生点**：从 38 个候选位置里抽一对，保证双方离场地中心等距、两点间距 26~52、不卡在障碍物内，且一出生就面朝对方
- **房主权威联机**：加入者只上报位置和开火，命中与伤害由房主裁决，血量以房主下发的数值为准，不会出现两边血量不一致
- **零依赖**：`server.js` 只用 Node 内置模块，不需要 `npm install`

## 快速开始

> ⚠️ 不要双击 `index.html` 打开。页面用 ES Module + importmap 加载 Three.js，`file://` 下会被浏览器安全策略拦掉，联机也会连到自己本机。**必须走 `http://`**。

### 启动服务器

Windows 直接双击 **`启动服务器.bat`**，或者命令行：

```bash
node server.js          # 默认 8000 端口
node server.js 9000     # 指定端口
```

看到 `联机大厅服务器已启动` 就成了（这个窗口别关），浏览器打开 <http://127.0.0.1:8000>。

### 单人模式

进游戏选 **单人模式**，直接开打机器人。

### 双人联机（同一 WiFi）

1. 只在**一台**机器上跑 `node server.js`（房主机器，启动时会把可用的局域网地址打印出来）
2. 双方浏览器打开 `http://<房主IP>:8000`
3. 都选 **双人单挑** → 一人「创建房间」拿到 4 位房间号 → 另一人加入 → 房主点开始

异地联机（内网穿透 / Tailscale / 端口映射）和连不上的排查，详见 **[README-联机方式.md](README-联机方式.md)**。

## 技术栈

- **前端**：单个 `index.html`（约 2300 行），Three.js（ES Module + importmap）+ `PointerLockControls`，无构建步骤、无打包工具
- **后端**：`server.js` 零依赖，一个进程同时提供
  - 静态 HTTP 服务（把 `index.html` 发给浏览器）
  - WebSocket 大厅中继（昵称登录、房间列表、创建 / 加入 / 离开、对局消息转发）
- **联机模型**：房主权威（host-authoritative）

## 项目结构

```

server.js             零依赖服务器：静态服务 + WebSocket 联机大厅
启动服务器.bat         Windows 一键启动
README-联机方式.md     联机排错与异地联机详解
test-mp.js            联机流程自测：建房 → 加入 → 双向中继 → 满员拒绝 → 离开解散
test-deep.js
test-reclaim.js
```

```bash
node test-mp.js
```

会自己拉起服务器、模拟两个浏览器客户端，把整套联机流程跑一遍，全绿说明服务器没问题。
